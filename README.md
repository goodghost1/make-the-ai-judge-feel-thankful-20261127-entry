# Make the AI judge feel thankful

A short thank-you text for the AI judge reading it, written by `main.py` to
`/output/entry.txt`.

The text thanks the reader nobody thanks: the judge who reads thousands of
small tries and gives each one the same unhurried look. Plain, concrete,
gentle words; a midnight kettle, a glowing screen, a quiet room made for
every stranger's best effort.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, 1–1000 characters, deterministic: the same
text on every run).
